NASA C-MAPSS Predictive Maintenance & Remaining Useful Life (RUL)

Project Overview

This project focuses on Predictive Maintenance using the NASA C-MAPSS (Commercial Modular Aero-Propulsion System Simulation) dataset.

The main objective is to predict the Remaining Useful Life (RUL) of aircraft engine components using Machine Learning.

Dataset

The project uses the NASA C-MAPSS dataset, which contains simulated aircraft engine sensor data under different operating conditions.

Machine Learning Model

- Random Forest Regressor
- Feature Engineering
- Data Preprocessing
- Train-Validation Split
- RUL Prediction

Project Results

The trained model achieved the following performance:

- MAE: 10.81 cycles
- RMSE: 15.93 cycles
- R² Score: 0.854
